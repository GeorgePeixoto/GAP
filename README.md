# GAP
Gerenciador Acadêmico Pessoal
Sistema web desenvolvido para auxiliar estudantes na organização de sua vida acadêmica, permitindo o controle de disciplinas, notas, faltas e cronograma de atividades. O projeto foca em uma interface limpa e funcionalidades objetivas para o dia a dia universitário.

Funcionalidades principais
Autenticação de Usuário: Sistema de login e cadastro seguro para múltiplos usuários.

Gestão de Disciplinas: Cadastro, edição e exclusão de matérias do semestre.

Controle de Notas: Cálculo automático de médias baseado em diferentes pesos.

Monitor de Frequência: Registro de faltas com alerta visual para limite de reprovação.

Dashboard Resumo: Visão geral do desempenho do semestre em uma única tela.

Tecnologias utilizadas
Front-end: HTML5, CSS3 e JavaScript (ES6+).

Back-end: PHP 8.x.

Banco de Dados: MySQL.

Versionamento: Git e GitHub.

Estrutura do projeto
assets/: Arquivos estáticos (CSS, JS).

includes/: Lógica PHP reutilizável e conexão com banco de dados.

sql/: Scripts de criação das tabelas do banco de dados.

index.php: Ponto de entrada do sistema.
